# Portfolio starter

An Astro multi-page portfolio starter using the **Index** direction: a clear Swiss-inspired grid, strong type, restrained colors, and room for detailed project stories.

## Run locally

```sh
npm install
npm run dev
```

Astro prints a local URL (usually `http://localhost:4321`). Use `npm run build` to create the static site in `dist/`.

## Where to change portfolio content

- `src/data/site.ts` — profile, contact, experience, education, skills, and learning focus.
- `src/data/projects.ts` — project summaries, stack, case study copy, and outcomes.
- `src/pages/ai.astro` — AI learning and product-building focus.
- `public/shashi-khatri-resume.pdf` — résumé download.
- `public/` — add project images here when ready.

The portfolio content is based on the supplied résumé. The AI Lab describes the learning and product-building focus shared by Shashi; specific AI project details can be added as they are ready to share.
